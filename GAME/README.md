# Пиксельный дозор

Оконная мини-игра на C++ и современном OpenGL. Весь код игры находится в одном файле — `main.cpp`. Программа запрашивает OpenGL 4.6 и при необходимости автоматически пробует версии ниже вплоть до 3.3. Фактическая версия драйвера отображается в заголовке игрового окна. Для отрисовки используются GLSL-шейдеры, VAO, VBO и `glDrawArrays`.

## Сборка и запуск в Windows

Открой PowerShell в папке проекта и выполни:

```powershell
g++ -std=c++17 -O2 -Wall -Wextra -static -mwindows main.cpp -lopengl32 -lgdi32 -luser32 -o pixel_patrol.exe
Start-Process .\pixel_patrol.exe
```

Или запусти `run.bat`: он соберёт программу и откроет игровое окно.

Сборка через CMake:

```powershell
cmake -S . -B build -G "MinGW Makefiles"
cmake --build build
Start-Process .\build\pixel_patrol.exe
```

## Управление

- `W`, `A`, `S`, `D` или стрелки — движение.
- `Пробел` или `Enter` — начать или перезапустить.
- `Esc` — закрыть окно.
- Собирай бирюзовые пиксели и избегай красных глитчей.

## Файлы

- `main.cpp` — вся программа: создание окна и OpenGL-контекста, игровой цикл, ввод, правила игры и отрисовка.
- `CMakeLists.txt` — настройки сборки через CMake; это конфигурация, а не второй файл с кодом игры.
- `run.bat` — команды Windows для сборки и запуска.
